# HW8 Monitoring

## Описание
Проект посвящён настройке мониторинга с использованием Prometheus и Grafana.

В рамках работы был создан дашборд Grafana для визуализации метрик Prometheus и экспортирован в файл `dashboard.json`.

## Состав проекта
- `docker-compose.yml` — файл запуска сервисов
- `prometheus.yml` — конфигурация Prometheus
- `dashboard.json` — экспортированный дашборд Grafana
- `screenshots/` — скриншоты результата

## Запуск проекта
Для запуска сервисов выполните команду:

```bash
docker compose up -d
```

После запуска будут доступны:
- Prometheus: `http://localhost:9090`
- Grafana: `http://localhost:3000`

## Настройка Grafana
1. Откройте Grafana в браузере.
2. Перейдите в раздел добавления источников данных.
3. Выберите **Prometheus**.
4. Укажите URL сервера Prometheus:
   - `http://localhost:9090`, если подключение идёт с хоста;
   - `http://prometheus:9090`, если Grafana и Prometheus работают в одной Docker-сети.
5. Нажмите **Save & Test**. Grafana имеет встроенную поддержку Prometheus как источника данных, поэтому отдельный плагин не требуется. [web:512][web:509]

## Импорт дашборда
Grafana позволяет импортировать дашборды из JSON-файла через меню **Dashboards → New → Import**. [web:484]

Шаги импорта:
1. Откройте **Dashboards**.
2. Выберите **New** → **Import**.
3. Загрузите файл `dashboard.json` или вставьте JSON вручную.
4. При необходимости выберите источник данных Prometheus.
5. Нажмите **Import**. [web:484][web:494]

## Содержимое дашборда
Дашборд содержит панели для базового мониторинга Prometheus:
- `up` — показывает доступность target;
- `sum(up)` — показывает суммарное количество доступных target.

Grafana хранит панели, переменные и настройки дашборда в JSON-модели, поэтому файл `dashboard.json` можно использовать для повторного импорта или переноса в другой экземпляр Grafana. [web:448]

## Проверка результата
После импорта дашборда и подключения источника данных на панелях должны отображаться метрики Prometheus.

Файл `dashboard.json` можно проверить двумя способами:
1. Открыть его в редакторе и убедиться, что это корректный JSON-объект.
2. Попробовать импортировать его обратно в Grafana через **Dashboards → New → Import**. Если Grafana принимает файл без ошибки, значит экспорт выполнен корректно. [web:448][web:484]
