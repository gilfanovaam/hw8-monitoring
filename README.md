# HW8 Monitoring

## Описание
Проект посвящён настройке мониторинга с использованием Prometheus и Grafana.  
В рамках работы был настроен сбор метрик Prometheus, создан и экспортирован дашборд Grafana (файл `dashboard.json`), а также подготовлены скриншоты результатов (`screenshots/`).

## Содержимое репозитория

- `prometheus.yml` — конфигурация Prometheus (глобальные интервалы и `scrape_configs`)
- `docker-compose.yml` (опционально) — запуск Prometheus и Grafana в Docker
- `grafana-dashboard.json` / `dashboard.json` — экспортированный дашборд Grafana
- `screenshots/` — скриншоты панели и (при возможности) алерта
- `README.md` — описание настройки и результатов

## Запуск проекта

### Через Docker Compose

1. Убедитесь, что установлен Docker и Docker Compose.
2. В корне репозитория выполните:

   ```bash
   docker compose up -d
   ```

3. После запуска сервисы будут доступны:

   - Prometheus: `http://localhost:9090`
   - Grafana: `http://localhost:3000`

### Без Docker (при необходимости)

1. Запустить `prometheus` с конфигом `prometheus.yml`.
2. Запустить Grafana (стандартная установка для вашей ОС).
3. Убедиться, что Prometheus слушает на `http://localhost:9090`, а Grafana — на `http://localhost:3000`.

## Настройка источника данных Prometheus в Grafana

1. Откройте Grafana в браузере: `http://localhost:3000`.
2. Войдите под пользователем `admin` (по умолчанию) и задайте новый пароль.
3. Перейдите в раздел  
   **Connections → Data sources → Add new data source**.
4. Выберите тип **Prometheus**.
5. В поле **URL** укажите:

   - `http://localhost:9090` — если Grafana и Prometheus работают на хосте;
   - `http://prometheus:9090` — если оба сервиса запущены в одной Docker-сети.

6. Нажмите **Save & test**. При успешной настройке Grafana подтвердит, что может обращаться к API Prometheus.

Grafana имеет встроенную поддержку Prometheus как источника данных, поэтому дополнительных плагинов не требуется.

## Импорт дашборда из JSON

Grafana позволяет импортировать дашборды из JSON через интерфейс:

1. В Grafana откройте  
   **Dashboards → New → Import**.
2. Загрузите файл `grafana-dashboard.json` (или `dashboard.json`)  
   либо вставьте его содержимое вручную.
3. При необходимости выберите ранее настроенный datasource Prometheus.
4. Нажмите **Import** — дашборд появится в списке доступных.

Файл JSON содержит модель дашборда (панели, запросы, настройки), поэтому может быть использован для переноса конфигурации на другой экземпляр Grafana.

## Содержимое дашборда

Дашборд демонстрирует базовый мониторинг Prometheus, в том числе:

- панель с метрикой `up` — показывает доступность целей (targets);
- агрегированное значение `sum(up)` — общее количество доступных целей.

При наличии дополнительного окружения дашборд может быть расширен другими метриками (например, временем отклика, нагрузкой на сервис и т.д.).

## SLO и результат

В рамках работы принимались следующие простые SLO:

- доступность сервиса мониторинга (Prometheus + Grafana) — не ниже 99%;
- время ответа мониторируемого сервиса — менее 1 секунды;
- периодичность сбора метрик Prometheus — 15 секунд.

Результат:

- Prometheus успешно запускается с конфигурацией `prometheus.yml`;
- Grafana успешно запускается и получает данные из Prometheus;
- дашборд успешно импортируется из JSON и отображает метрики;
- подготовлен отчёт по дрифту данных с помощью Evidently (в отдельном ноутбуке);
- скриншоты интерфейса Grafana и дашборда размещены в каталоге `screenshots/`.

При работе в Google Colab дополнительно возникало ограничение по безопасности (`origin not allowed`) при доступе к Grafana через прокси, поэтому часть визуализации была выполнена через API и локальное окружение.
